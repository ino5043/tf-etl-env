# ダッシュボード仕様 — 工場長 朝会レポート

| 項目 | 値 |
|------|-----|
| 利用シーン | 工場長が毎朝 AM 8:00 の生産会議で前日実績を確認する |
| ページ構成 | 1. 生産実績 / 2. 品質管理 / 3. 設備稼働 |
| データソース | `semantic-model.md` のセマンティックモデル（Direct Lake） |
| メジャー | `dax-measures.md`（以下、メジャー名は `[ ]` で表記） |
| キャンバス | 16:9（1280 × 720） |

---

## 1. 共通仕様

### 1.1 朝会での見方

| 観点 | 設計 |
|------|------|
| 「前日」の扱い | 期間スライサー内の**最終データ日**を「対象日」とし、カードはすべて `(最終日)` 系メジャーで表示する。パイプラインが AM 8:00 までに前日分を書き込めば、操作なしで前日実績が出る |
| トレンド | 折れ線・ヒートマップは期間スライサーの全期間（推奨: 直近 30 日）を表示する |
| 読む順番 | 各ページとも 左上（カード）→ 中央（トレンド）→ 下段（ライン別・設備別の内訳）の Z 型に配置する |
| 色 | 良好 / 注意 / 異常 の 3 色だけを使う（`09_書式` の色メジャー）。それ以外の装飾色は使わない |

### 1.2 共通ヘッダー（全ページ同じ位置）

| # | ビジュアル | 設定 |
|---|-----------|------|
| H1 | テキスト ボックス | ページ名（例: 「生産実績」） |
| H2 | カード | `[最終日]`（ラベル: 「対象日」） |
| H3 | カード | `[最終集計日時 (JST)]`（ラベル: 「データ更新」） |
| H4 | スライサー（期間） | `dim_date[calendar_date]`、スタイル: 「次の値の間」 |
| H5 | スライサー（ライン） | `dim_line[line_name]`、スタイル: ドロップダウン、複数選択可、「すべて選択」を表示 |

- H4・H5 は「スライサーの同期」で 3 ページすべてに同期する
- 期間スライサーの初期値はデモ前に「最終データ日の 29 日前 〜 最終データ日」に設定して保存する。データが毎日更新される本番運用では「相対日付: 過去 30 日（今日を含まない）」に切り替える
- ページ間はページ ナビゲーター（ボタン）で移動できるようにする

### 2.4 デモで見せるポイント

- 開いた瞬間に「対象日 = 前日」「データ更新 = 今朝 4 時台」が見える。Excel 集計で AM 10:00 過ぎていた作業がなくなったことを示す
- P7 の**合計行の達成率**は各ラインの達成率の平均ではなく、合計から再計算した工場全体の値である（`dax-measures.md` 1 章の例）
- 未達ラインを右クリック →「設備稼働」へドリルスルーし、そのラインの設備に異常がないかをその場で確認する

| 項目 | 設定 |

| E5・E6 の期間 | 列が多すぎる場合は期間スライサーを直近 14 日にする |

### 4.4 デモで見せるポイント

- E5 で「色が日を追って 緑 → 黄 → 赤 に変わる設備」が予兆保全の対象である。停止してからではなく、上昇傾向の段階で保全計画を組める
- アラート判定（65℃ / 3.5 mm/s）はパイプライン側で済ませており、ダッシュボードとアラート通知が同じ基準で動く
- 稼働率は「簡易」と明記している。データにない指標を作らない姿勢を示し、OEE への拡張（稼働ログの追加）を次のステップとして提案する

## 6. デモ前チェックリスト

| # | 確認項目 | 確認方法 |
|---|---------|---------|
| 1 | 最新日の Gold データが入っている | ヘッダーの「対象日」がサンプルデータの最終日と一致する |
| 2 | 期間スライサーが直近 30 日（最終日まで）になっている | 開いた状態でグラフの右端が最終日 |
| 3 | 色の出るデータがある | 不良率 5% 超のライン × 日が 1 つ以上、温度または振動アラートの設備が 1 台以上ある（サンプルデータ生成時に意図的に含める） |
| 4 | 「(空白)」行が出ていない | ライン・設備のマトリックスに空白行がない（`semantic-model.md` 4.4 の参照整合性チェックが 0 件） |
| 5 | ドリルスルーが動く | P7 → 設備稼働 で E5 がそのラインの設備だけになる |
| 6 | 共有設定 | デモ視聴者のアカウントでワークスペースまたはレポートの閲覧権限がある |
| 7 | 予備 | ネットワーク不調に備えて各ページのスクリーンショットを用意する |
